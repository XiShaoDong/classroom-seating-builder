## Card Deck Slider Component — Implementation Plan

A single-card-focused deck navigation component, styled after a physical stack of cards (Apple Wallet / shuffle feel), built with the project's existing conventions: React 19 + TS, **inline-style objects** (no Tailwind, no animation library — pure CSS transitions), lucide-react icons.

### Files to create

1. **`src/src/classroomSeatBuilder/components/CardDeck/SeatLayoutPreview.tsx`** — read-only mini grid that renders a seating layout (uses the app's existing 40px-cell convention), so cards visualize real seat templates.

2. **`src/src/classroomSeatBuilder/components/CardDeck/CardDeckSlider.tsx`** — the reusable core component:
   - Tracks `headIndex` + `direction` state; cycles infinitely.
   - All cards `position: absolute` inside a relative stage; each card derives a transform from `(index - headIndex)`:
     - head (offset 0): full size, opacity 1, top z-index, no transform
     - behind (offset -1,-2,-3): `translateY(+offset)` `scale(<1)` slight `rotate`, reduced opacity, lower z-index → stacked depth cue
   - **Forward** = head card lifts up + rotates and flies to the back of the stack, next card comes forward (shuffle feel). **Backward** = reverse.
   - Transition: `transform .45s cubic-bezier(.2,.8,.2,1), opacity .35s`.
   - Next/Prev buttons (lucide `ChevronLeft/Right`) + keyboard arrow support.
   - Pointer/drag intentionally omitted per scope, but component API leaves room to add it.

3. **`src/src/classroomSeatBuilder/components/CardDeck/CardDeckSliderDemo.tsx`** — demo page with 5 cards, each a distinct seating layout (Single Seat, 双人桌, Small Classroom, U-Shape, Custom Block), showing icon + title + description + `SeatLayoutPreview`.

### Files to modify

4. **`src/src/classroomSeatBuilder/style/styles.ts`** — append a `cardDeck` style block (stage, card, nav button, depth layers) following the existing inline-object + `as const` pattern.

5. **`src/App.tsx`** — add a toggle to switch between `ClassroomEditor` and `CardDeckSliderDemo` so both views remain accessible.

### Constraints honored
- Not a carousel: one active card, no horizontal side-by-side, no snap-scroll.
- Physical deck mental model; subtle rotation + scaling + depth layering.
- Matches existing code style (named `Props` interface, default export, `styles` import, `as const` casts).
